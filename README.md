# 电商智能客服问答系统

**基于 RAG 与 Agent 的多品类电商客服：用户提问后，系统先从知识库
检索相关资料，再基于检索结果生成回答。知识库未覆盖的问题会明确
拒答，不编造内容。**

**覆盖品类**：扫地机器人故障和养护、服饰养护、尺码推荐、配色建议等。


## 功能亮点

- **知识库增量同步**：文件增改自动检测入库，删除自动清理，
  无需手动重建（含库内一致性校验，防止状态不一致）
- **拒答机制**：知识库未覆盖的问题明确拒答，不编造内容；
  9 个拒答样本实测全部正确拒答
- **量化评测体系**：30 题测试集（检索题 + 拒答题），
  检索命中率: 21/21 = 100.0%（附一键评测脚本）
- **多轮对话**：支持上下文连续交互
- **多品类知识库**：覆盖扫地机器人、服饰养护、尺码、配色等品类


## 环境要求

- Python 3.13+
- 需要三个 API Key：
  - DeepSeek（大模型）
  - DashScope（向量嵌入，阿里云百炼）
  - Tavily（联网搜索工具，可选）
