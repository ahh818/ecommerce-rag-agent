# 电商智能客服问答系统

**基于 RAG 与 Agent 的多品类电商客服：用户提问后，系统先从知识库
检索相关资料，再基于检索结果生成回答。知识库未覆盖的问题会明确
拒答，不编造内容。**

**覆盖品类**：扫地机器人故障和养护、服饰养护、尺码推荐、配色建议等。


## 功能亮点

- **知识库增量同步**：文件增改自动检测入库，删除自动清理，
  无需手动重建（含库内一致性校验，防止状态不一致）
- **拒答机制**：知识库未覆盖的问题明确拒答，不编造内容；
  9 个拒答样本实测全部正确拒答
- **量化评测体系**：30 题测试集（检索题 + 拒答题），
  检索命中率: 21/21 = 100.0%（附一键评测脚本）
- **多轮对话**：支持上下文连续交互
- **多品类知识库**：覆盖扫地机器人、服饰养护、尺码、配色等品类

## 技术架构

```
用户提问
    │
    ▼
┌─────────────┐
│  Streamlit  │  前端界面（app.py）
└──────┬──────┘
       ▼
┌─────────────┐
│    Agent    │  决定调哪个工具（DeepSeek 驱动）
└──────┬──────┘
       ▼
┌─────────────┐
│    工具层    │  rag_summarize / get_weather
└──────┬──────┘
       ▼
┌─────────────┐     ┌─────────────────┐
│   RAG 检索   │────▶│  向量库 (Chroma)  │  问题向量化后检索相似片段
└──────┬──────┘     └─────────────────┘
       ▼
  检索片段 + 用户问题
       │
       ▼
┌─────────────┐
│    大模型    │  基于片段生成回答（无依据则拒答）
└──────┬──────┘
       ▼
      回答
```

用户提问 → Agent 判断意图并调用工具 → RAG 检索向量库取回相关片段
→ 大模型基于片段生成回答。检索不到依据时明确拒答，不编造。

- **Agent 层**：LangChain create_agent + DeepSeek，负责工具调度
- **RAG 层**：DashScope 嵌入 + Chroma 向量库，增量同步知识库
- **知识库**：8 个商品知识文件，覆盖选购/安装/保养/故障/耗材等场景


## 技术要点

**切块策略经实验调优**

初始参数（chunk_size=50）把知识切成碎片（436 个片段，平均 31 字），
检索时返回半截内容。通过评测集对比实验，调整为 200 字 + 20 字重叠后，
片段数降至 121，平均长度 155 字，原本因碎片化而漏检的问题恢复命中。

**拒答机制：从距离阈值到语义判断**

先试距离阈值方案，量化后发现负样本距离（0.49-0.81）与正样本
（0.17-1.09）严重重叠，单一阈值必然误伤（拦全负样本需牺牲 16 题
正确答案）。原因是向量检索只判断"像不像"，不判断"有没有答案"。
改用提示词层语义判断后，9 个拒答样本全部正确拒绝，且未误伤正样本。

**知识库同步：双重校验防止状态不一致**

同步判定采用"MD5 比对 + 向量库实际内容校验"双重条件：仅当文件
未变化**且**库中确实存在该文件的片段时才跳过。单一 MD5 判定（旧实现）
在同步中断或库重建后会把缺失文件永久跳过，导致"记录显示已同步、
实际检索不到"且无法自愈。


## 环境要求

- Python 3.13+
- [uv](https://docs.astral.sh/uv/)（依赖管理）
- API Key（缺一不可）：

| 变量 | 用途 | 申请地址 |
|---|---|---|
| `DEEPSEEK_API_KEY` | 大模型对话 | DeepSeek 开放平台 |
| `DASHSCOPE_API_KEY` | 文本向量嵌入 | 阿里云百炼控制台 |

> `TAVILY_API_KEY` 为预留配置（联网搜索功能规划中，当前未接入）。

## 快速开始

### 安装

```bash
git clone https://github.com/ahh818/ecommerce-rag-agent.git
cd ecommerce-rag-agent
uv sync
```

### 配置

复制环境变量模板并填入自己的 Key：

```bash
copy .env.example .env
```

### 启动

```bash
.venv\Scripts\streamlit.exe run app.py
```

浏览器访问 `http://localhost:8501`。

启动时会自动同步知识库：首次运行需调用嵌入接口重新生成向量
（约 1-2 分钟），控制台会打印每个文件的同步状态。

### 运行评测

```bash
.venv\Scripts\python.exe eval\run_eval.py
```

输出每题命中情况、分类统计与总体检索命中率。

### 常见问题

**启动时报 `uv trampoline failed to canonicalize script path`**

项目目录被移动或重命名，导致虚拟环境中启动器记录的绝对路径失效。
重建环境即可：

```bash
uv sync
```

**中文显示乱码**

Windows CMD 默认使用 GBK 编码。知识库文本文件必须保存为 UTF-8；
在 CMD 中查看中文输出前可先执行 `chcp 65001`。

**启动时提示缺少 API Key**

确认 `.env` 文件位于项目根目录（与 `app.py` 同级），且已填入
`DEEPSEEK_API_KEY` 与 `DASHSCOPE_API_KEY`。
